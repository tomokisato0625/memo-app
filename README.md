# メモアプリ

Flaskを使用して作成したシンプルなメモアプリです。

## 使用技術

- Python
- Flask
- MySQL
- SQLAlchemy
- PyMySQL
- HTML
- CSS
- Git / GitHub

## 機能

- メモの一覧表示
- メモの新規作成
- メモの詳細表示
- メモの編集
- メモの削除
- 作成日時の表示

## 工夫した点

- FlaskとMySQLを接続し、データをデータベースに保存できるようにしました。
- SQLAlchemyを使用してデータベースを操作しています。
- HTMLとCSSを使用して画面を作成しました。
- Gitを使用して開発内容を管理しています。

## 開発環境

- Windows
- Visual Studio Code
- Python
- MySQL
